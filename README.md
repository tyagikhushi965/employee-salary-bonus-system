# Employee Salary and Bonus Management System

DBMS case study: stored procedure, cursor-based bonus processing, salary updates and an employee-wise report.

Open `index.html` in a browser to see the interactive demo. The MySQL code is in the "SQL code" tab.

Bonus rule: rating 5 = 20%, 4 = 15%, 3 = 10%, 2 = 5%, 1 = 0% of basic salary.
